# Overview

firnR is an R package to assist the modeling and interpretation of snow, firn and ice data including water isotopes

# Installation
firnR can be installed directly from Bitbucket using the devtools R package by executing the following code in an R terminal:
```
library(devtools)
install_bitbucket("ecus/firnR")
```
